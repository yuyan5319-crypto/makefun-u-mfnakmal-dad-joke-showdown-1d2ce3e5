Dad Joke Showdown: one original dad joke, told out loud, about a dad, a fridge, and a pair of googly eyes — with a pun that lands on the very last word.

> I stuck googly eyes on the fridge so it can see food for what it really is. My wife asked why. I said, 'Because it's the coolest thing in this kitchen.'

## Run it

```sh
node main.ts
```

The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. It refuses to run if the joke is not 1–200 characters, so the gate can never see an invalid entry.
